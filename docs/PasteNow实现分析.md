# PasteNow 实现分析

分析对象：本机 `/Applications/PasteNow.app`，版本 2.32（build 790），开发者 Tutu Studio，最低系统 macOS 14.6，通用二进制（x86_64 + arm64）。

分析方法只用了静态手段：读 `Info.plist`、签名与 entitlements、`otool -L`（链接库）、`nm -u`（导入的系统符号）、`strings`（类名、日志、本地化文案）、Core Data 模型，以及本机数据库的**表结构和聚合统计**。没有做运行时注入，也没有反汇编；数据库里只看了表结构和计数，没有读取任何剪贴板内容。

> ⚠️ 本机这份安装包不是官方构建：签名的 `Authority=https://macked.app`、`TeamIdentifier=not set`，
> `Contents/Frameworks/` 里多出一个 `macked.app.dylib`，并且被主程序加载（`otool -L` 输出的最后一行）。
> 这是第三方注入的动态库，下面的分析没有涉及它。出于安全考虑，建议改用 Mac App Store 或官网的正版安装包。

## 1. 总体形态

| 结论 | 证据 |
| --- | --- |
| Swift + AppKit 原生应用，局部用 SwiftUI | `otool -L` 链接了 `AppKit`、`SwiftUI`、`libswiftCore` 等；类名有 `AppDelegate`、`MainWindowController`、`PasteViewController`、`PasteListViewController`；`Resources/` 下有 `.nib` 和 `.storyboardc` |
| 菜单栏常驻，没有 Dock 图标 | `Info.plist`：`LSUIElement = true`；导入了 `NSStatusItem` |
| 同时有 App Store 版和官网直销版 | `_MASReceipt/`、`StoreKit`、`AppReceipt`/`ReceiptManager`；同时内置 `Sparkle.framework` 2.9.4，`Info.plist` 里有 `SUPublicEDKey` |
| 模块化 | `PasteNowKit.framework`（持久化：`PersistenceController`、`AppGroupPersistentContainer`、`Compressor`）、`CloudSyncKit`，以及 `ShortcutKit` / `SmartListKit` / `AutoStartKit` / `ActivationKit` / `PurchaseKit` 等 SwiftPM 资源包 |

## 2. 剪贴板监听：定时器轮询 `changeCount`

macOS 没有公开的“剪贴板变化”通知，PasteNow 用定时器比较 `NSPasteboard.changeCount`：

- 日志字符串：`Starting check pasteboard timer, interval: %f`、`On auto check pasteboard: count change from: %ld to %ld`、`Update monitor pasteboard interval: %f`
- 导入：`scheduledTimerWithTimeInterval`、`changeCount`
- 菜单 “Clipboard Monitoring Interval” 提供三档：`Very Frequent (0.1 Second)` / `Frequent (0.5 Second)` / `Normal (1 Second)`
- 来源应用：导入了 `frontmostApplication`；`ZPASTEITEM.ZAPPBUNDLEID` 字段和 `ZAPPLICATION` 表（含图标 `ZICON`）
- 暂停/恢复：`Info.plist` 声明了 `StopMonitoringClipboardIntent` / `ResumeMonitoringClipboardIntent`（可以用“快捷指令”控制）

## 3. 过滤规则（Exclusion Rules）

- 遵循 [nspasteboard.org](http://nspasteboard.org) 约定：二进制里有 `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType`，日志 `Receive concealled type, auto ignore.`、`Is transient type: %{bool}d, …`
- 通用剪贴板：日志 `Receive remote type, ignore for now…`，选项 “Ignore clipboard data from iOS devices”
- 按应用排除：`ZEXCLUDERULE` 表关联 `ZAPPLICATION`；文案 “PasteNow will ignore the copy operation if the app in the "Exclusion Rules" list.”；`ZPASTESTATS.ZDEFAULTEXCLUDERULESCREATED` 说明首次启动时会创建一批默认排除规则
- 其他选项：忽略超过指定大小的内容、忽略空白内容、Excel 内容超过 100 KB 时只保存纯文本

## 4. 存储：Core Data + SQLite（App Group 容器）

- 模型：`PasteNowKit.framework/Resources/PasteNow.momd`，共 4 个版本（`Shared` … `Shared 4`），实体有 `Action`、`Application`、`ExcludeRule`、`PasteItem`、`PasteItemData`、`PasteList`、`PasteStats`
- 位置：`~/Library/Group Containers/KAQ3M6FSM7.app.pastenow.PasteNow/Documents/PasteNow.sqlite`（WAL 模式）；entitlements 中的 `com.apple.security.application-groups` 对应这个目录
- `ZPASTEITEM` 主要字段：`ZTEXT`、`ZTITLE`、`ZBASEUNIFORMTYPE`、`ZSECONDARYUNIFORMTYPE`、`ZCHECKSUM`、`ZAPPBUNDLEID`、`ZCOPYCOUNT`、`ZTIMESTAMP`、`ZTHUMBNAILIMAGE`、`ZRTFDATA`、`ZURLDATA`、`ZFILEURLDATA`、`ZTEXTFORMATPOLICY`、`ZLIST`；模型里的索引有 `byChecksumIndex`、`byTimestampIndex`、`byTextIndex`、`byTitleIndex`、`byBaseUniformTypeIndex`、`byAppBundleIDIndex`
- **完整数据压缩存放**：`ZPASTEITEMDATA` 里本机 2181 条记录全部是 `ZCOMPRESSED = 1`。数据第一个字节是 `0x01`（Core Data 的“内联存储”标记），后面紧跟 `bvxn` / `bvx2`，也就是 Apple Compression 框架里 LZFSE/LZVN 数据块的魔数；较大的数据放在 `.PasteNow_SUPPORT/_EXTERNAL_DATA/<UUID>` 文件里，文件同样以 `bvx2` 开头（Core Data 的 “Allows External Storage”）。日志 `Compress pasteItemDataArrayData with %f%% successfully` 说明它把所有 pasteboard 类型序列化成一个数组后整体压缩
- **按指纹去重**：日志 `Create SHA1 checksum for public type %s, data size: %ld`、`PasteItem with checksum %s is already exists, just update it`，导入了 `CC_SHA1`。本机 `ZCHECKSUM` 全是 8 位十六进制；抽样 50 条纯文本，有 12 条与 `SHA1(文本)` 的前 8 位完全一致（随机撞上的概率可以忽略）。其余条目不一致，推测参与哈希的不是显示用的文本本身，而是带格式的那份数据
- 缩略图：`ZTHUMBNAILIMAGE` 为 `0x01` 加 PNG 数据（`89 50 4E 47`）
- 类型分布（聚合统计）：`public.text` 1822 条，`public.image`（tiff/jpeg/png）197 条，`public.url` 102 条，其余为 `public.file-url`
- 持久化历史：`NSPersistentHistoryTrackingKey`、`NSPersistentStoreRemoteChangeNotification`，以及 `ACHANGE` / `ATRANSACTION` 表，用于在多个进程和同步之间合并变更

## 5. 唤出面板：Carbon 全局热键 + 浮动 NSPanel

- 热键：导入了 `RegisterEventHotKey` / `UnregisterEventHotKey` / `InstallEventHandler` / `GetEventParameter`，相关类是 `CarbonShortcutManager`、`HotKey`。这套 API 不需要辅助功能权限
- 默认快捷键：偏好设置里 `shortcutkit-show-interface = {carbonKeyCode = 9; carbonModifiers = 768}`，即 `kVK_ANSI_V` 加 `cmdKey(256) | shiftKey(512)`，也就是 **⇧⌘V**
- 键盘布局：导入了 `TISCopyCurrentASCIICapableKeyboardLayoutInputSource`、`UCKeyTranslate`、`kTISPropertyUnicodeKeyLayoutData`、`LMGetKbdType`，用来把键码换算成当前布局下的字符（显示快捷键、查找 V 键的键码；设置里还有 Dvorak 布局选项）
- 面板：`FloatPanel` / `PasteFloatPanel`（`NSPanel` 子类）、`canBecomeKey`、`NSVisualEffectView`、`MovableGlassEffectContainerView`（macOS 26 的 Liquid Glass 效果）。定位用的是 `mouseLocation` 加 `NSScreen`，对应选项 “Appear near Cursor / Appear at Last Position”；偏好 `float-panel-size = {360, 787}` 记录面板大小
- 键盘操作：`LocalEventMonitor` / `RunLoopLocalEventMonitor` 加 `addLocalMonitorForEventsMatchingMask:handler:`；支持 HJKL 导航；日志 `Assign key code %s to item` 对应数字键快速粘贴；`QuickPreviewController` 提供预览

## 6. 粘贴：写回剪贴板，再模拟 ⌘V

- 导入：`CGEventSourceCreate`、`CGEventCreateKeyboardEvent`、`CGEventSetFlags`、`CGEventPost`；权限检查用 `AXIsProcessTrustedWithOptions` 加 `kAXTrustedCheckOptionPrompt`
- 日志：`Paste %ld item to frontmost app`、`Simulate paste item: accessibility permission denied`、`Simulate paste item: no avaiable key code`
- 文案：“Paste operation requires the accessibility feature”，以及引导用户把图标拖进“辅助功能”列表的说明
- 选项：“Paste to Active App”、“%@ to Paste Plain Text”、“Move Items to the Top after Pasting”，菜单 “Paste As → Plain Text / 带项目符号的纯文本”

## 7. 其他能力

- iCloud 同步：有 `CloudKitManager`、`CKRecord`；每个实体都带 `ZRECORDID`、`ZRECORDDATA`、`ZDIRTYKEYS`、`ZSYNCED` 字段，说明是自己实现的 CloudKit 同步（保存 CKRecord 系统字段和脏字段），容器为 `iCloud.app.pastenow.PasteNow3`
- 开机启动：`Contents/Library/LoginItems/PasteNowHelper.app`（`LSBackgroundOnly`），配合 `LoginServiceKit`、`LSSharedFileList*` 和 `ServiceManagement`
- 列表与智能列表：`ZPASTELIST` 表（`ZLISTTYPE`、`ZFILTERRULEDATA`）、`SmartListModel`、`PredicateTypeModel`；文案 “Items added to normal list won't be removed”
- 历史清理：“Remove History Items” 可选 1 天到 1 年，或手动清理
- 杂项：URL Scheme `pastenow://`、Sentry 崩溃上报、LinkPresentation 抓取链接标题（Labs 功能）、文本和图片编辑窗口

## 8. 在本项目中的对应实现

| PasteNow 机制 | 本项目（Rust + egui） |
| --- | --- |
| NSTimer 轮询 `changeCount` | `monitor.rs` 后台线程轮询，间隔可选 0.1 / 0.25 / 0.5 / 1 秒 |
| 读取所有 pasteboard item 的所有类型 | `platform/pasteboard.rs`，基于 objc2-app-kit |
| nspasteboard.org 标记、按应用排除、大小限制、空白内容 | `devtools-clipboard/src/rules.rs`；先只读类型列表判断标记，命中时连数据都不读 |
| SHA1 指纹去重 | `uti.rs`：对“主要表示”计算 SHA-256（取前 128 位） |
| Core Data + LZFSE + 外部存储 | `store.rs`：SQLite（WAL）+ zstd；压缩后超过 256 KB 的数据写到 `blobs/` 目录 |
| PNG 缩略图 | `thumbnail.rs`（image crate，最长边 640） |
| Carbon `RegisterEventHotKey` | `hotkey.rs`，使用 global-hotkey crate（macOS 上底层是同一个 API），默认 ⇧⌘V |
| `FloatPanel` + `NSVisualEffectView`，从菜单栏点开时贴在图标下方 | `platform/panel.rs`：在内容视图下方插入 `NSVisualEffectView`；点击菜单栏图标时根据 `NSStatusBarWindow` 的位置定位，快捷键唤起时用 `NSEvent::mouseLocation` 加 `NSScreen` 定位 |
| 卡片左侧的来源应用图标（`ZAPPLICATION.ZICON`） | `platform/icons.rs`：`NSWorkspace` 取应用图标转 PNG，界面按 bundle id 缓存 |
| `CGEventPost` 模拟 ⌘V + 辅助功能检查 | `platform/keyboard.rs`：同样的 CGEvent / AX / TIS / UCKeyTranslate 调用 |
| `LSUIElement` + `NSStatusItem` | winit `ActivationPolicy::Accessory` + tray-icon |
| LoginItems 辅助应用 | `platform/login_item.rs`：LaunchAgent plist |
| 普通列表 / 智能列表 | 用户列表（内置“收藏”）+ 固定的类型分类（文本 / 链接 / 图片 / 文件） |

## 9. 没有实现或做法不同的部分

- **iCloud 同步**：需要 Apple 开发者账号和 CloudKit 容器，没有实现
- 智能列表的自定义谓词、文本和图片编辑、Quick Look、链接标题抓取、快捷指令 Intents、URL Scheme、音效，都没有实现
- 面板窗口：eframe 创建的是普通 `NSWindow`，不是非激活的 `NSPanel`。弹出时会激活本应用并记住之前的前台应用，粘贴前再把焦点还给它，然后发送 ⌘V
- 压缩算法用 zstd 代替 LZFSE，指纹用 SHA-256 代替 SHA1
