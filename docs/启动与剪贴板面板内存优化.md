# 启动与剪贴板面板内存优化

## 原因与本轮范围

原实现启动时把系统字体完整读到堆中，并通过 `Box::leak` 保留。本机苹方 TTC
约 75 MiB，加上 SF Pro、SF Mono、Menlo，原始字体数据合计约 85 MiB。
各字体族本来已经共享文件数据，问题在于完整读取整个字体集合。

此外，隐藏的主窗口仍会初始化 eframe / wgpu；玻璃管线原来在启动时编译，
打开面板后创建整窗离屏纹理及两张半宽半高的模糊纹理。缩略图最多缓存 300 项，
没有像素字节预算，隐藏面板也不释放。

本轮保留 egui / wgpu 和现有视觉效果，先处理资源加载与缓存生命周期。
没有更换渲染后端，也没有改变剪贴板历史、图片预览清晰度或搜索模块的索引策略。

## 修改

1. 字体改为 `memmap2` 只读文件映射，仍按文件路径共享，实际访问哪些页才加载哪些页。
   `memmap2` 已在锁文件中，新增直接依赖不引入另一套字体引擎。
   egui 的字体接口接受静态切片，因此映射及文件句柄保留到进程结束。
   macOS 候选均为系统字体；Windows 保留只允许共享读取的句柄，防止映射期间文件被
   写入、截断或删除。映射失败时回退到原有读取方式，保持字体可用。
2. 缩略图缓存增加 16 MiB 像素数据预算，并保留 300 项上限以约束解码失败记录。
   超限时淘汰最近最少使用的条目，不再整个清空。该预算只针对缓存持有的纹理，
   不代表整个进程、解码临时缓冲或 GPU 驱动的内存上限。
3. 面板隐藏 30 秒后释放缩略图、应用图标、富文本样式、大预览和玻璃离屏纹理。
   短时间切换保留缓存；清理完成后不再周期唤醒隐藏窗口。搜索窗口和贴图的资源不在清理范围内。
4. 玻璃着色器和管线延迟到首次捕获背景时创建。闲置时清空离屏纹理与持有它们的绑定组，
   保留管线，避免每次打开都重新编译。

eframe 0.36 在所有窗口隐藏时只执行 `logic`，不会提交 egui 的纹理释放队列。
因此闲置清理除丢弃 `TextureHandle` 外，还会通过 `Frame` 的渲染状态释放对应 GPU 纹理。
下次绘制时 egui 队列里重复的释放操作是安全的，重新加载的纹理使用新的编号。

## 字体对照测量

2026-11-18，macOS，同机、同一测试分别运行修改前后的测试可执行文件，
用 `/usr/bin/time -l` 读取 `maximum resident set size`，换算为 MiB：

| 独立测试 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 组装字体族 `families_put_system_fonts_first` | 93.8 MiB | 9.4 MiB |
| 实际中英文排版 `fallback_baselines_match_primary` | 97.6 MiB | 14.4 MiB |

这是单次独立字体测试的峰值 RSS，不是完整应用的待机内存或面板内存。
映射的虚拟地址范围仍包含整个字体文件，虚拟内存大小不能作为本轮收益指标。
随着访问更多字形，映射的驻留页会增长，进程的图形驱动与分配器也可能保留高水位。

## 验证与复查

- `cargo check -p devtools-hub --offline`
- `cargo check -p devtools-hub --features windows-typecheck --offline`
- `cargo test --workspace --offline`
- `cargo test -p devtools-hub snapshot --offline -- --ignored`
- `cargo build --release -p devtools-hub --offline`

macOS 的私有测试剪贴板、系统图标和 GPU 离屏渲染需要访问对应系统服务；
在限制这些服务的沙箱内运行会失败，应在允许这些服务的环境中执行。
Windows 类型检查不代替 Windows 原生运行测试，也不覆盖 `cfg(windows)` 下的字体文件共享行为。

新增的缓存测试检查字节预算、LRU 次序和失败记录上限。
`snapshot_glass_resources_rebuild` 使用真实 GPU 玻璃管线，验证隐藏未满 30 秒保留缓存、
超过阈值后没有绘制帧也能释放 GPU 缩略图，并比较重新加载后与释放前的画面。

实际应用复查应使用同一 Release 构建、同一数据目录、同一屏幕缩放比例：
记录冷启动待机、首次打开面板、滚动图片历史、隐藏超过 30 秒和再次打开五个阶段。
比较时保持文件搜索是否启用及索引状态一致。测量前退出旧实例，不同时运行两个监听实例。
