# 系统关机与统一退出清理

## 退出入口

Windows 使用 `platform/windows/session.rs` 创建隐藏的顶层窗口，在独立线程运行消息循环。
它不是仅消息窗口，因此能接收系统会话广播；主窗口隐藏、最小化、正在显示搜索窗口时也继续监听。

- `WM_QUERYENDSESSION`：立即返回 TRUE，不提前停止任务。
- `WM_ENDSESSION` 且 `wParam=FALSE`：关机取消，不改变应用状态。
- `WM_ENDSESSION` 且 `wParam=TRUE`：关机、重启、注销或 Restart Manager 确认关闭应用，调用统一退出入口。
- 托盘退出、更新重启：`AppEvent::Quit` 转入同一入口。
- 普通窗口关闭、事件循环结束：`on_exit` 兜底；启动失败时主函数仍会停止已经启动的后台任务。

系统监听窗口只负责通知与等待，不持有 UI 的可变引用，也不在 UI 线程等待 UI 自己处理退出。
参考 [WM_QUERYENDSESSION](https://learn.microsoft.com/en-us/windows/win32/shutdown/wm-queryendsession)
与 [WM_ENDSESSION](https://learn.microsoft.com/en-us/windows/win32/shutdown/wm-endsession)。
本次系统消息监听针对 Windows；macOS 的正常退出复用公共收尾流程，未新增 macOS 关机会话监听。

## 清理顺序

`Shared::request_exit` 设置全局停止信号，停止接受新事件、禁止再打开面板、禁用快捷键操作并唤醒后台等待。
`HubApp::prepare_exit` 在 UI 线程执行一次：

1. 取消更新任务，注销全局快捷键和托盘图标；Windows 鼠标钩子线程退出前调用 `UnhookWindowsHookEx`。
2. 停止滚动截图与截图看门狗，关闭遮罩、贴图和菜单；丢弃未完成的截图/OCR 接收端。
3. 关闭剪贴板查询通道，取消文件搜索扫描、查询和监听，刷新待写搜索历史并保存搜索窗口尺寸。
4. 保存软件设置，释放图片、图标和面板预览缓存。
5. 在共同截止时间内等待剪贴板监听、查询、截图/OCR、贴图纹理和更新任务结束，再尝试合并 SQLite WAL。
6. 通知系统监听线程清理完成，主动关闭根视口、结束事件循环。系统会话退出时跳过更新后的自动重启。

剪贴板监听和自动更新不再用长时间 `sleep` 等待下一轮，而是通过退出条件变量立即唤醒。
已经开始的数据库事务或更新原子替换应自行结束；不能中途强行杀掉某个 Rust 工作线程。
搜索任务使用模块原有的取消机制，历史文件通过原子替换保存；未完成的扫描不会代替最后一个有效快照。
本次不会自动保存尚未导出的截图、贴图或编辑器草稿，也不会在系统退出时弹出保存对话框。

## 等待上限与兜底

- 后台线程共用 3 秒等待预算；只 join 已结束的线程，不对单个线程无限等待。
- 系统监听窗口最多等待 4 秒，然后返回系统；不会阻止关机。
- 普通退出有 6 秒看门狗，覆盖 UI 没有消费退出请求、保存/系统调用卡住，以及清理完成后事件循环仍未结束。
- 已完成的清理不会再次执行。不能取消的系统 OCR、网络请求或文件系统调用超过预算时会记录任务名称；
  最终由进程结束释放剩余资源。系统强制结束进程、断电不可能保证所有待写数据完成。

## 验证

自动测试只向测试自己的隐藏窗口发送会话消息，不调用真实关机或注销 API：

- 查询和取消关机不触发退出，确认会话结束才调用处理器。
- 退出信号幂等、能唤醒长时间等待的后台任务，后到的系统会话标记不会丢失。
- 无响应任务不会导致 join 无限等待。
- UI 收尾保存设置、停止任务、关闭贴图和查询通道；重复收尾不会再次写配置，退出后不再接受截图请求。

沿用本机测试设置：临时目录位于项目的 `target/test-temp`，避开沙盒临时目录的原子替换权限限制；
原生右键菜单测试会加载本机第三方 Shell 扩展，继续单独跳过该已知不稳定测试。
